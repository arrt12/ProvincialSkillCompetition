## 📚 프로젝트 개요
- **프로젝트명:** Time Forest
- **설명:**
-  여러 움직임 클립을 가중치 기반으로 블렌딩하여 오브젝트 이동을 자연스럽게 제어
   Unity Timeline에 커스터마이징된 트랙과 클립을 직접 추가, 맞춤형 시네마틱 흐름 구성이 가능하도록 설계
   VolumeController를 통해 Vignette, 노출, 컬러 조정 등 후처리 효과를 실시간으로 조절하게 하여, 감정과 분위기 표현까지 Timeline과 연계해 강화
  - Unity
  - C#
  - Blender
